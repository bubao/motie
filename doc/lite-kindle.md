# 练字版（Kindle）说明

## 定位与交互

- **定位练字**：为 Kindle 等黑白墨水屏精简——固定「整页描红」，汉字浅色、字格灰色；没有颜色 / 深浅 / 模板 / 拼音 / 标题等控件。做字帖（笔顺演示、导出 PDF）请使用完整版。
- **设置收进弹窗**：顶栏主操作「内容 / 字体 / 字格」与次要操作「示例 / 清空」分组；内容弹窗支持「插入空格（空临格）」与实时字数 / 页数统计，清空需二次确认；字格弹窗为竖排大点击区（田 / 米 / 米字回 / 回）。预览区不被占用。
- **预览交互**：点击字格 → 遮罩放大该字，顶部显示「第 N / M 字 · 字」，底部为「‹ 上一个 / 退出 / 下一个 ›」大按钮；同时保留点中间字格退出、点左 / 右边缘（各约 15%）切换、← / → / Esc；按 ↑ / ↓ 逐字移动并高亮当前字（`.cell.is-current`）；顶部状态栏显示字数 / 页数 / 当前字；输入框聚焦时不拦截按键。
- **目标环境**：Kindle 实验浏览器（WebKit / NetFront 内核，仅支持 ES5 与常规 CSS，可能禁用 localStorage）。
- **产物**：`lite/index.html`——CSS 与 JS 全部内联，约 35 KB，**无需联网、可离线打开**，也可复制这一个文件单独分发。
- **固定参数**：整页描红、墨色 `35,38,43`、描红深浅 0.62、格子 80 px、字格灰色，不读取完整版的配置残留（内容 / 字格样式 / 字体地址除外）。

## 服务模式（Kindle 可用字体）

Kindle 实验浏览器不支持 IndexedDB，无法用完整版的本地字体库。用 Go 内核作服务器（内嵌前端产物与 lite，`make run`；端口取配置，默认 39130）：

- 标准版 `http://<本机IP>:<端口>/index.html`：字体管理器里点「发布」，把本地字体上传到内核用户字体库（仅 http 服务模式下显示该按钮）。
- Kindle 打开 `http://<本机IP>:<端口>/lite/index.html`：字体区会拉取 `GET /api/fonts` 的用户字体列表，点击即经 `/api/fonts/file/<id>` 加载应用；`file://` 直开时无服务，列表自动隐藏。
- 文件名限 ASCII（老浏览器 `@font-face` 对中文路径支持差），中文显示名在列表中展示。
