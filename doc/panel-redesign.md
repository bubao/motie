# 左侧栏重设计（rail + 面板）

> 对象：标准版左侧栏（`web/src/Panel.jsx` 的 rail 与面板、`web/src/App.jsx` 的顶栏）。
> 目标：功能归属清晰、高频操作高效、消除重复入口、补齐危险操作确认与「格子恒显」开关。
> 依据：[网页功能设计](web-features.md) 的「格子恒显」原则与 P0 清单。

## 1. 现状诊断

### 1.1 结构性问题（归属错乱）
| # | 问题 | 位置 |
| --- | --- | --- |
| S1 | **预设**（版式快照）放在「输出」页，逻辑上属版式 | `SettingsGroup` @ 输出页 |
| S2 | **元信息**（姓名 / 日期 / 页码）放在「版式」，实为打印产物 | `MetaGroup` @ 版式页 |
| S3 | **设置 JSON 导入导出**塞在「输出」页，与输出动作无关 | `SettingsGroup` @ 输出页 |
| S4 | **「关于」混入 rail**，与内容/版式/字格/文字/输出同级 | `RAIL_MAIN` + rail 底部 |
| S5 | **打印 / 导出 PDF 重复入口**：顶栏与输出页各一套（同一 `usePdfExport`） | `App.jsx` + `OutputActions` |

### 1.2 内容页拥挤
| # | 问题 |
| --- | --- |
| C1 | 示例库 `select` 与「示例」按钮功能重复 |
| C2 | 5 个工具按钮（插入空格 / 示例 / 导出 / 导入 / 清空）+ 重复字统计全堆在主区，主次不分 |
| C3 | **「清空」无二次确认**，误清空不可恢复（lite 已加确认，标准版缺失） |

### 1.3 层级与入口
| # | 问题 |
| --- | --- |
| L1 | **字体管理**埋在「文字」页底部，功能重（导入/列表/删除）但入口轻 |
| L2 | **主题切换在顶栏**，外观设置无归属 |
| L3 | rail 6 项偏多；窄屏为 rail + 面板 + 预览三栏，挤压 |

### 1.4 缺项
| # | 问题 |
| --- | --- |
| M1 | 字格页无**空临格样式开关**（实线 / 虚线）——与「格子恒显」原则呼应 |
| M2 | 无内容撤销 / 重做（误改、误清空无退路） |

## 2. 重设计：信息架构

### 2.1 rail（保留 5 项，移除关于）
```
内容 · 版式 · 字格 · 文字 · 输出
```
- 「关于」移出 rail（见 2.3）；窄屏 rail 折叠为纯图标条（保留文字 tooltip）。

### 2.2 各页职责（重新划分）
| 页 | 保留 | 移入 | 移出 |
| --- | --- | --- | --- |
| 内容 | textarea、标题、行/页统计 | — | 工具收进「内容工具」折叠区 |
| 版式 | 模板、描红比例、每行格数、行距字距、纸张、边距 | **预设（保存 / 载入 / 删除）** | 元信息 → 输出 |
| 字格 | 样式、颜色、大小 | **空临格样式（实线 / 虚线）** | — |
| 文字 | 颜色、深浅、拼音、笔顺 | — | — |
| 输出 | 导出 PDF、打印 | **元信息（姓名 / 日期 / 页码）**、导出 / 导入 JSON | 预设 → 版式 |

### 2.3 顶栏与辅助入口
- 顶栏保留：品牌 + 版本、主题（浅 / 深 / 跟随系统）、**导出 PDF**、**打印**（高频动作）。
- 「关于」与「设置 JSON」合并为顶栏「更多」菜单（或面板底部次级入口），不再占 rail。

### 2.4 内容页布局
```
[内容]  换行分段，空行分页；空格即空临格
[textarea]
[标题（可选）]
已输入 N 行 · 约 M 页
[内容工具 ▸]  折叠区：插入空格 / 示例库 / 导入 txt / 导出 txt / 清空(二次确认)
[重复字统计]   折叠展示
```

### 2.5 危险操作与反馈
- 清空：二次确认（与 lite 一致）。
- 内容编辑：Ctrl/Cmd+Z 撤销（至少覆盖清空 / 粘贴 / 导入覆盖）。
- 打印 / 导出中：按钮禁用 + 文案（现有）。

## 3. 组件与文件改动清单

- `web/src/Panel.jsx`
  - `RAIL_MAIN` 去掉 `about`；`railItem` 支持 tooltip
  - `SettingsGroup` 拆为 `PresetGroup`（移版式页）与 `SettingsIO`（移输出页 / 更多菜单）
  - `MetaGroup` 移到输出页
  - `ContentTools`：工具折叠 + 清空确认 + 去重复（示例库 select 与「示例」二选一）
  - 字格页新增空临格样式字段（`ConfigSchema` 同步）
- `web/src/App.jsx`：顶栏加「更多」菜单（关于 + 设置导入导出）
- `web/src/styles.css`：rail 折叠、折叠区、预设列表样式
- `js/config.js`：新增 `BlankStyle`（'line' | 'dash'）字段 + 校验

## 4. 分期

1. **结构归位**（S1–S5）：预设→版式、元信息→输出、设置→更多、关于移出 rail、顶栏/输出去重
2. **内容页重组**（C1–C4）：工具折叠、清空确认、示例去重
3. **字格与文字**（M1、L1）：空临格样式、字体分区
4. **全局**（M2、L2、L3）：撤销、窄屏折叠、主题归属

## 5. 验收

- 每个预设的保存 / 载入 / 删除后，预览与 PDF 一致（预设只含偏好，不含内容与标题）。
- 清空必须二次确认；确认后内容清空、统计归零。
- 窄屏（≤720px）rail 折叠为图标，面板可滚动。
- 空临格样式切换后，屏幕 / 打印 / PDF 三处一致。
- `npm test` 全绿；`npm run build` 通过。
