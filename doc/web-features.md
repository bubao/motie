# 网页功能设计（标准版 + Kindle 单文件）

> 范围：网页标准版（`web/` + `js/` + `css/`）与 Kindle 版（`lite/`）。桌面 app 不在本期范围。
> 目标：把「输入汉字 → 排版 → 打印 / 导出」做得顺手，并补上内容生产、版式复用、分享与离线能力。

## 1. 设计原则

- **纯前端、离线优先**：标准版构建为单文件（`dist/index.html`）；**Kindle 版始终是零依赖单文件**（`lite/index.html`，`file://` 直开、可拷进 Kindle）。
- **字格恒显**：格子是载体，字可有可无。任何模板、任何内容下，**每页都铺满行、每行都完整呈现格数**；空格即空临格（画格不画字），行尾自动补满，页尾不足的行补空临格。**不因无字而缺格，也不因空格而丢格。**
- **不接入 AI**：不做 AI 导入 / 生成 / 组词；内容靠手动输入、示例库与文件导入。
- **不做账号与后端**：数据用 localStorage / IndexedDB，跨设备靠导出 / 导入。
- 尊重上游：字格、字体、打印样式与现有实现保持一致，不重复造轮子。

## 2. 渲染核心：格子恒显

这是本设计的硬约束，先于功能：

- 每行固定 `cols` 格（自适应或用户指定）；内容字符数 < `cols` 时用**空临格**补满，内容超长按列换行。
- **每页铺满**：每页输出 `rows`（首页含标题时 `rowsFirst`）行；内容不足的行补空临格，使每页都是完整字帖纸。补满行不计入模板 decay 的行号。
- 内容中的空格 = 一个空临格；真空行 = 分页；纯空格行 = 一整行空临格。
- 模板（正常 / 整页描红 / 一字三描红 / 首字范字 / 空临格）**只决定格内字的角色与深浅**（范字 / 描红 / 空白），**不决定是否画格**。
- 格子样式（田 / 米 / 回 / 作文 / 数字）是表现层，不改变格数；空临格与有字格使用同一套字格，仅无字。相邻字格共享边界线（屏幕 / 打印 / PDF 均为单线）。

**验收**：
- 全空格内容、单字内容、超长内容、纯空格行，四种输入下每行格子数都 = `cols`；
- 单字 / 少字内容下，每页仍输出 `rows` 行格子（页尾补空临格），不是只画有字的行；
- 任意模板下空格行 / 行尾 / 段中空格都渲染为完整格子；
- `npm test` 中「空临格 / 补满 / 空格行」用例覆盖上述场景。

## 3. 功能地图

### A. 内容与生产（不接 AI）
- A1 **示例库**：分类（古诗 / 词语 / 笔画 / 数字）+ 搜索 + 收藏（本地）。
- A2 **文件导入**：txt / md 读入，自动分段；拖拽 / 文件选择。
- A3 **内容工具**：字数 / 页数实时统计、重复字检测、章节（多页）、按字数截取。
- A4 **拼音 / 笔顺**：现有按需加载；补多音字标注与降级说明。

### B. 版式
- B1 **模板预设**：保存 / 命名 / 载入 / 删除 / 分享（预设 = 模板 + 字格 + 页边距 + 行距组合）。
- B2 **模板增强**：现有模板上支持「描红 : 临写比例」连续可调、行首标题。
- B3 **页面**：A4 / Letter / 自定义尺寸、页边距、行距、每行格数、整页居中。
- B4 **标题 / 落款**：内容标题 + 可选落款行。

### C. 字格与字体
- C1 **字格**：7 种样式 × 3 色 + 线条粗细微调（空临格与有字格同一套字格，仅无字）。
- C2 **字体库**：本地字体导入（IndexedDB）+ 预览 + 授权提示；浏览器无法枚举系统字体，保持「导入制」。
- C3 **笔顺 / 拼音开关**：独立开关、设置持久化。

### D. 导出与分享
- D1 **PDF**：A4 导出，补文件名、文档元信息、多页。
- D2 **图片导出**：整页 PNG（手机保存 / 分享）。
- D3 **打印样式**：隐藏操作面板（已有），补页眉页脚策略、「仅打印选中页」。
- D4 **分享**：URL 编码（内容 + 配置）+ 二维码；配置 / 预设导出 JSON 可导入。

### E. 离线与安装
- E1 **PWA**：manifest + service worker + 离线缓存 + 安装到桌面 / 手机。
- E2 **完全离线**：`vendor` 内联（pinyin-pro / HanziWriter），断网可用全部核心功能 + 拼音 / 笔顺。
- E3 **数据备份**：配置 + 预设 + 最近内容导出 / 导入。

### F. 易用与无障碍
- F1 **键盘与焦点**：面板可达、焦点顺序、可见焦点。
- F2 **对比度与字号**：对比度达标、界面字号档。
- F3 **空状态与引导**：首次进入示例与提示。
- F4 **响应式**：手机 / 平板可用。

## 4. 优先级

| 优先级 | 功能 | 理由 |
| --- | --- | --- |
| P0 | **格子恒显**（含测试）、A3、B1、C1、C2、D1、D4、E1、Kindle 单文件维护 | 核心闭环 + 产品硬约束 |
| P1 | B2、B4、C3、D2、E3、F1、F3 | 完成度与无障碍 |
| P2 | A1 增强、A4、B3 文档化、D3、F2、F4 | 锦上添花 |

## 5. 分期路线

- **一期**：格子恒显补齐（含测试）→ A2 / A3 → B1 → C1 / C2 → D1 / D4 → E1
- **二期**：D2 / D3 / E3 / F1 / F3
- **三期**：B2 / B4 / A1 / F2 / F4

每期验收：`npm test` 全绿、`npm run build` 通过、`file://` 直开冒烟、目标机型（手机 / 平板 / Kindle）实测。

## 6. 数据与存储设计

- 配置：`localStorage` 键 `zitie.config`（沿用，两版共用）。
- 预设：新增 `zitie.presets`（名称 + 配置快照 + 时间）。
- 字体：IndexedDB `zitie-fonts`（已有），新增授权提示字段。
- 分享：小内容编码进 URL；大内容改为导出 JSON 文件。
