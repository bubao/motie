# 网页功能设计（标准版 + Kindle 单文件）

> 范围：网页标准版（`web/`，核心在 `web/src/core/` + `css/`）与 Kindle 版（`lite/`）。桌面 app 不在本期范围。
> 目标：把「输入汉字 → 排版 → 打印 / 导出」做得顺手，并补上内容生产、版式复用、分享与离线能力。

## 1. 设计原则

- **纯前端、离线优先**：标准版构建为单文件（`dist/index.html`）；**Kindle 版始终是零依赖单文件**（`lite/index.html`，`file://` 直开、可拷进 Kindle）。
- **字格恒显**：格子是载体，字可有可无。任何模板、任何内容下，**每页都铺满行、每行都完整呈现格数**；空格即空临格（画格不画字），行尾自动补满，页尾不足的行补空临格。**不因无字而缺格，也不因空格而丢格。**
- **不接入 AI**：不做 AI 导入 / 生成 / 组词；内容靠手动输入、示例库与文件导入。
- **不做账号与后端**：数据用 localStorage / IndexedDB，跨设备靠导出 / 导入。
- 尊重上游：字格、字体、打印样式与现有实现保持一致，不重复造轮子。

## 2. 渲染核心：格子恒显

这是本设计的硬约束，先于功能：

- 每行固定 `cols` 格（自适应或用户指定）；内容字符数 < `cols` 时用**空临格**补满，内容超长按列换行。
- **每页铺满**：每页输出 `rows`（首页含标题时 `rowsFirst`）行；内容不足的行补空临格，使每页都是完整字帖纸。补满行不计入模板 decay 的行号。
- 内容中的空格 = 一个空临格；真空行 = 分页；纯空格行 = 一整行空临格。
- 模板（正常 / 整页描红 / 一字三描红 / 首字范字 / 空临格）**只决定格内字的角色与深浅**（范字 / 描红 / 空白），**不决定是否画格**。
- 格子样式（田 / 米 / 回 / 作文 / 数字）是表现层，不改变格数；空临格与有字格使用同一套字格，仅无字。相邻字格共享边界线（屏幕 / 打印 / PDF 均为单线）。

**验收**：
- 全空格内容、单字内容、超长内容、纯空格行，四种输入下每行格子数都 = `cols`；
- 单字 / 少字内容下，每页仍输出 `rows` 行格子（页尾补空临格），不是只画有字的行；
- 任意模板下空格行 / 行尾 / 段中空格都渲染为完整格子；
- `npm test` 中「空临格 / 补满 / 空格行」用例覆盖上述场景。

## 3. 功能地图

### A. 内容与生产（不接 AI）
- A1 **示例库**：分类（古诗 / 词语 / 笔画 / 数字）+ 搜索 + 收藏（本地）。（已实现，2026-11-27：SAMPLES 全条目带 `cat`；示例库由下拉改为「搜索框（名称或内容）+ 分类 chips（全部 + 当前模式出现的分类）+ 列表项（名称 + 单行截断预览）+ 星标收藏」；收藏存 `localStorage` 键 `zitie.sample-favs`、置顶且可取消；仍只列当前模式示例，避免跨模式误填）
- A2 **文件导入**：txt / md 读入，自动分段；拖拽 / 文件选择。（另含粘贴长文一键「清洗排版」：trim / 折叠空行 / 汉字后半角标点转全角，2026-11-27 / Z4）
- A3 **内容工具**：字数 / 页数实时统计、重复字检测、章节（多页）、按字数截取。（全部已具备，2026-11-27：「按字数截取」落地于内容工具区——输入 N 保留前 N 字、入撤销历史；「章节（多页）」即既有空行分页 + 「插入空白页」能力）
- A4 **拼音 / 笔顺**：现有按需加载；补多音字标注与降级说明。（多音字已实现：pinyin-pro 按词定音，行级语境查询；离线静默降级。）

### B. 版式
- B1 **模板预设**：保存 / 命名 / 载入 / 删除 / 分享（预设 = 模板 + 字格 + 页边距 + 行距组合）。
- B2 **模板增强**：现有模板上支持「描红 : 临写比例」连续可调、行首标题。（已实现，2026-11-27：`TraceRatio` 10–100% 描红浓度连续可调——默认 50 与旧「自动减半」一致，预览 / PDF 同源；`ShowPageTitle` + `PageTitleScale` 每页首行之上显示内容标题并可调字号。对应需求编号 Z1=C-a / Z2=C-b）
- B3 **页面**：A4 / Letter / 自定义尺寸、页边距、行距、每行格数、整页居中。（已实现，2026-11-27：预设尺寸 + 自定义宽高；页级微调：预览每页提供「删去本页 / 与下页合并」（Z3）；纸张底色 / 纹理：预设色 + 自定义 hex + 宣纸纤维 / 洒金纹理，屏幕 / 打印 / PDF 三端同源（C-d））
- B4 **标题 / 落款**：内容标题 + 可选落款行。标题已由 Z2=C-b 落地（`ShowPageTitle` / `PageTitleScale`，每页 / 仅首页）；落款于 2026-11-27 补齐：`ShowSignature` / `SignatureText`——每页右下角小字（格高 ×0.36、楷体栈、页脚灰），屏幕与打印同一 DOM，PDF/PNG 由 `core/pdf.js` 同条件绘制。lite 精简版不同步（与标题一致）。
- B5 **页脚评分栏**：姓名 / 日期 / 页码之外的可选「得分：＿＿＿＿」（屏幕 / 打印 / PDF 三态一致）。（已实现，2026-11-26）

### C. 字格与字体
- C1 **字格**：7 种样式 × 3 色 + 线条粗细微调（空临格与有字格同一套字格，仅无字）。辅助线细分（C-g）：米字 / 田字的十字、对角线、回字内框统一走「内部线样式」（实线 / 虚线 / 无）+「虚线样式」（划线 / 圆点 / 点划线）与密度，外框可独立设置（已实现）。
- C2 **字体库**：本地字体导入（IndexedDB）+ 预览 + 授权提示；浏览器无法枚举系统字体，保持「导入制」。（授权提示已实现：导入区固定合规提醒。曾评估过「按字体登记授权字段」，因个人练字场景价值有限、且与桌面字体库模型不对称，按收敛原则回退为纯提示，避免过度设计）
- C3 **笔顺 / 拼音开关**：独立开关、设置持久化。（已实现：「显示拼音」总开关 `ShowPinyin`、「格上拼音条」`PinyinBar`（与格型 '10' 双向联动）、点击播放 `StrokeAnim`、静态笔顺序号 `StrokeOrder`，全部落 config 持久化）
- C4 **字体管理增强（F-a~c）**（已实现，2026-11-27）：
  - F-a 分组标签：用户字体支持标签（≤8 个、每个 ≤20 字，仅管理元数据不动文件名）；列表内联编辑，上方 chips 一键按标签筛选；桌面端 `POST /api/fonts/tags` → `fonts.UpdateTags`，浏览器端存 FontStore。
  - F-b 列表搜索与排序：名称即时过滤 + 排序切换（导入顺序 / 按名称 / 按大小 / 启用优先）；无匹配时与「尚未导入」分开提示。
  - F-c 批量导入进度与失败清单：导入中按钮显示「导入中 N/M」，结束后成功汇总与失败清单（含原因）toast 分列展示。
- C5 **笔画粗细**（C-c）（已实现，2026-11-27）：字本身的描边加粗（区别于格子线宽 `ZgLineScale`），配置 `InkWidth` 0–80 步进 5（0 = 默认，相当于字号的 0–8%）；屏幕 / 打印用 `-webkit-text-stroke`，PDF 用 canvas `strokeText` 同源模拟；与「字体粗细」（normal / bold）叠加生效。

### D. 导出与分享
- D1 **PDF**：A4 导出，补文件名、文档元信息、多页。
- D2 **图片导出**：整页 PNG（手机保存 / 分享）。（已实现，2026-11-26：浏览器 / 桌面均可用；2026-11-27 / C-e：输出页可选分辨率 96–384dpi，默认 144dpi，PDF 仍为 1.5×）
- D3 **打印样式**：隐藏操作面板（已有），补页眉页脚策略、「仅打印选中页」。（已实现，2026-11-26：输出页「打印范围」支持 `2` / `1,3-5`；实测 11 页选第 2 页时仅该页进入打印，打印后恢复；2026-11-27 / C-f：新增「打印缩放」，默认自动按约 200mm 安全宽度等比缩小，避免页宽超出纸张导致右侧裁切，可手动设百分比）
- D4 **分享**：URL 编码（内容 + 配置）+ 二维码；配置 / 预设导出 JSON 可导入。（全部已实现，2026-11-27：输出页「分享链接」复制 `#s=` URL、「分享二维码」弹层 canvas 渲染（qrcode-generator，bundle 进单文件）；实测 canvas 深色模块 3 万像素、DOM/几何/文案校验通过）

### E. 离线与安装
- E1 **PWA**：manifest + service worker + 离线缓存 + 安装到桌面 / 手机。（已实现，2026-11-26：仅 http(s) 协议且未接内核（mock）时注册 SW；断网可开已实测。2026-11-27：注册语义由 `test/sw.e2e.test.mjs` 端到端锁定——自动注册 / 激活 / 稳定存活，http 模式与 file:// 不注册）
- E2 **完全离线**：`vendor` 内联（pinyin-pro / HanziWriter），断网可用全部核心功能 + 拼音 / 笔顺。（已实现：`--vendor` 构建把资源来源写死为本地 vendor；配合 PWA 缓存实测断网可渲染）
- E3 **数据备份**：配置 + 预设 + 最近内容导出 / 导入。（已实现：配置早有独立 JSON 导出 / 导入（SettingsIO）、预设已有分享链接 / JSON（G5）；2026-11-27 补齐整包备份 `core/backup.ts`——设置 / 预设 / 字帖库 / 最近文件及内容打成一个带校验头的 JSON，「更多」页数据备份组仅本地模式显示，导入为合并语义（同名跳过、按 path 去重、保留本机草稿、字帖 id 冲突重分配），写回快照后刷新生效。单测见 `test/backup.test.jsx`）

### G. 字帖管理（桌面端）
- G1 **最近字帖入口**（已实现，2026-11-27）：面板新增「字帖」页。内容源是本机 txt/md 文件（内部 files 服务的安全子树 workspace/export），索引存 SQLite（`internal/library`，表 documents：路径/标题/字数/收藏/归档/时间）。进入页面自动把最近文件并入索引并展示；点条目读回内容直接开练。浏览器（非桌面）模式下用内存 mock 保持 UI 可预览。（2026-11-28 修复字数快照断裂：此前 `documents.chars` 无任何生产写入者，编辑既有字帖后列表字数恒为初始值——现由 files 服务落盘后经 `SyncContentStats` 刷新 `chars`/`updated_at`，保留用户命名与收藏；store 级 + API 级测试锁定）
- G2 **打开 / 另存**（已实现，2026-11-27）：字帖页「打开…」选本机 txt/md 载入（桌面端同步落盘工作区）；「另存为…」把当前内容存为工作区字帖，同名需确认覆盖；保存后立即入库刷新。
- G3 **重命名 / 删除 / 搜索**（已实现，2026-11-27）：搜索框按标题/路径即时过滤；改名只改列表标题（文件名不动）；删除需二次确认，移除内容文件与索引条目（最近列表同步清理，不会复活）。
- G4 **收藏置顶**（已实现，2026-11-27）：条目星标一键收藏，列表按「收藏优先、时间次之」排序。
- G5 **预设导入导出**（已实现，2026-11-27）：具名预设可「复制分享链接」（`#p=`，base64url 版本化，复用 D4 编码）或「导出 JSON」；「导入…」浮层支持粘贴链接 / 选择 JSON 文件，先预览识别数量再合并，同名跳过不覆盖。仅含版式白名单字段，不含内容与字体。

M1–M4 字帖管理四件套（入口 / 打开另存 / 改名删除搜索 / 收藏）已全部完成。

### F. 易用与无障碍
- F1 **键盘与焦点**（已实现，2026-11-27）：rail 与折叠区可 Tab 到达；`:focus-visible` 统一描边；浮层（分享二维码 / 预设导入）用 `useFocusTrap` 圈定焦点、Esc 关闭并返还焦点，dialog 标 `aria-modal`；`.rp-skip-link` 直跳预览主区。单字放大预览原来自建同款焦点陷阱，已统一收敛到同一 hook（U4）。
- F2 **对比度与字号**（AA 已实测达标，2026-11-27）：目标等级 WCAG 2.1 AA（见 §7 第 5 条），由 `test/a11y.e2e.test.mjs`（axe-core 真实页面全状态扫描，违规清零）+ `test/contrast.test.mjs`（相对亮度公式回归明/暗变量组合，含强调态暖底）双重守护；暗色主按钮底色改用 `--cinnabar-deep`，`--ink-soft` 加深为 `#666D78`。界面字号档已统一（2026-11-27）：`css/main.css` `:root` 定义六档 `--fs-xs: 11px / --fs-sm: 12px / --fs-md: 13px / --fs-lg: 15px / --fs-xl: 16px / --fs-2xl: 22px`（预览纸内字号由毫米值派生、不入档）；`web/src/styles.css` 66 处游离 px 全部收敛，新增 `test/font-scale.test.mjs` 守卫（无游离 px + 引用档位必须已定义）。
- F3 **空状态与引导**（已打磨，2026-11-27）：预览区空态带「查看示例」引导；导出 / 打印对空内容统一前置提示（共用 `hasExportableContent` 判定）；列表页区分「加载失败」与「还没有字帖」；离线导致拼音 / 笔画资源不可用时给出一次降级提示，并在资源状态行显示失败项。
- F4 **响应式**（已实现，2026-11-27）：≤720px 时 rail 常驻 44px 图标条、面板转为覆盖式抽屉（点 rail 开、点遮罩 / Esc 关）；层级修复后抽屉打开时 rail 与顶栏仍可点，缩放条沉到遮罩下。CSS 断点与 JS `matchMedia` 一致性由 `test/responsive.test.mjs` 守卫。
- F5 **交互一致性**（已统一，2026-11-27）：忙碌态一律「禁用 + spinner + 文案」（导出三键、字体导入、列表刷新、检查更新、字帖打开中、笔顺播放中）；禁用滑杆改用降权色与 `not-allowed` 光标，不再「看起来可拖」；提示 / 二次确认统一走 toast 与内联确认态，无原生 `window.confirm/alert`；不变量由 `test/interaction-consistency.test.mjs` 守卫。
- F6 **主题视觉走查**（已核对，2026-11-27）：明/暗两套主题的对比度与层级经桌面、窄屏抽屉、单字放大浮层、空内容 toast、单元重复字格页共 10 张截图逐张核对，未发现缺陷；深色下预览纸保持白底（打印友好），禁用滑杆灰化与可用滑杆区分明显，暗色主按钮对比度由自动化测试守护。
